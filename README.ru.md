# Battle of Heroes in Terminal

[English](README.md) · [Русский](README.ru.md)

Пошаговая консольная игра-битва на C++ с созданием персонажа, цветным выводом и полосками здоровья.

## Возможности

- Меню создания персонажа
- Игрок, враг и питомец
- Цветной вывод в терминале и полоски здоровья

## Начало работы

Нужен компилятор C++ (например, `g++`).

```bash
g++ play.cpp -o play
./play
```

## Структура проекта

- `play.cpp` — вся игра
