# Battle of Heroes in Terminal

[English](README.md) · [Русский](README.ru.md)

A turn-based console battle game in C++ with character creation, colored output and health bars.

## Features

- Character creation menu
- Player, enemy and pet characters
- Colored terminal output and health bars

## Getting Started

Requires a C++ compiler (for example `g++`).

```bash
g++ play.cpp -o play
./play
```

## Project Structure

- `play.cpp` — the whole game
